# بنك الدم المركزي — النسخة Enterprise

## ما تم تطويره
- إدارة المستشفيات والمديرين والموظفين.
- مخزون فردي لوحدات الدم مع FEFO وتواريخ صلاحية وحالة الوحدة.
- طلب دم بين المستشفيات مع كشف الموردين حسب التوفر الفعلي.
- قبول الطلب = حجز ذري للكمية المطلوبة تلقائياً.
- تجهيز ثم تسليم مع ربط الوحدات بالطلب ومنع التسليم المكرر.
- إشعار المورد فقط عند إنشاء الطلب مع نافذة وصوت قابل للتعطيل.
- تتبع منشئ الطلب والموظفين المنفذين للمراحل.
- لوحة تحكم بمخططين: النظام بالكامل + المستشفى، مع اختيار المستشفى للمدير العام.
- ملف شخصي: اسم، اسم مستخدم، هاتف، صورة Base64، إعداد صوت التنبيه.
- تغيير كلمة المرور بعد تأكيد القديمة.
- آخر دخول.
- وضع ليلي.
- قائمة جانبية قابلة للفتح والإغلاق على الكمبيوتر والهاتف مع السحب والتمرير المستقل.
- تقارير وطباعة وتصدير CSV وسجل تدقيق.

## التشغيل
1. انسخ `.env.example` إلى `.env` وضع `VITE_SUPABASE_URL` و`VITE_SUPABASE_ANON_KEY`.
2. نفذ migrations داخل مجلد `supabase/migrations` بالترتيب.
3. انشر Edge Function:
   `npx supabase functions deploy create-user`
4. ثبت الحزم:
   `npm install`
5. شغل:
   `npm run dev`
6. للفحص:
   `npm run typecheck`
   `npm run build`

> لا تحذف أي migration سابق؛ migration الأخير يضيف/يعدل الوظائف المطلوبة ويحافظ على البيانات الحالية.
